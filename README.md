# Scroll-Driven Hero Animation

A modern scroll-driven hero section created as a frontend internship assignment. The project focuses on smooth animations, responsive design, and scroll-based interactions.

## 🚀 Live Demo

[View Live Project](https://sandeepshahu33.github.io/scroll-hero-animation/)

## ✨ Features

* Scroll-driven hero section animation
* Letter-by-letter headline reveal animation
* Staggered statistics animation on page load
* Smooth scroll-based visual movement
* Scroll progress indicator
* Responsive design for desktop and mobile
* Smooth transitions using GSAP ScrollTrigger
* Optimized animations using CSS transforms

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* React.js
* Tailwind CSS
* GSAP
* GSAP ScrollTrigger
* Vite

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/sandeepshahu33/scroll-hero-animation.git
```

Go to the project folder:

```bash
cd scroll-hero-animation
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 📦 Build for Production

```bash
npm run build
```

The production files are generated inside the `dist` folder.

## 🌐 Deployment

The project is deployed using **GitHub Pages** with **GitHub Actions**.

Every push to the `main` branch triggers the deployment workflow automatically.

## 🎯 Assignment Objective

The main objective of this project was to create an engaging hero section where the visual experience responds to the user's scroll instead of relying on an autoplay animation.
